# Founder Tip Tuesday: week of October 13, 2026

Vercel COO Jeanne DeWitt Grosser told Tomasz Tunguz how Vercel moved inbound sales to an AI agent. The best rep wrote the first instructions, humans reviewed the agent's work until it was ready, and the rules with one answer every time later moved out of the instructions and into code.
